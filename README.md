# 🔴 Red Hound

> **A unified cybersecurity, system monitoring, and intelligence dashboard.**

Red Hound is a sophisticated cybersecurity and system-monitoring GUI built to bring a wide range of technical capabilities together into a single, modern interface.

Designed with a futuristic command-center aesthetic, Red Hound provides a collection of tools for system analysis, network monitoring, reconnaissance, automation, and security research.

---

## ⚡ Features

| Module | Description |
|---|---|
| 🖥️ **System Monitoring** | Monitor system resources and hardware activity |
| 🌐 **Network Monitoring** | View and analyze network information |
| 🔎 **OSINT** | Open-source intelligence and reconnaissance tools |
| 📷 **Flock Detection** | Detect nearby Flock Cameras |
| 📡 **WiFi/Bluetooth Scanner** | Discover nearby wireless devices |
| 📺 **IR Blaster** | Control compatible infrared devices |
| 🔐 **Crypto Library** | Collection of cryptographic utilities |
| 🤖 **AI Chatbot** | Integrated AI-powered assistant |
| 🔌 **Port Scanner** | Scan systems for accessible network ports |
| 🕵️ **Steganography Tools** | Tools for analyzing and working with hidden data |

---

## 🖥️ Interface

Red Hound brings everything together through a single unified GUI, allowing different tools and monitoring systems to be accessed without switching between multiple applications.
